# Rookery

An agent orchestrator desktop app. Commission work as a **brief** — the outcome, the repos, and what
_"done"_ means — shape an **approach** for how it's tackled, drop **checkpoints** where you want to
hold the reins, and send it into **flight**. Agents do the work inside an isolated copy of your
repos; you're called only when a decision is genuinely yours, and the whole flight reads back as the
**story** of the change — a complete audit trail of everything meaningful that happened.
